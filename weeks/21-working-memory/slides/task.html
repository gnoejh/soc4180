Part 1 · The task

A list of 16 pushes, held as it comes

The pushes

Week 20's: 100 N for 0.1 s, one of 8 directions in the robot's own frame, every 1.2-2 s, sensed by the pelvis accelerometer (0.93 right).

The buffer

Each percept is written in by its position in the list. Before each write, everything already there fades by γ = 0.75.

The question

After 16 pushes: "which way was push 1? push 2? ... push 16?" Scored against what the robot perceived.

The list is longer than the memory on purpose: the question is not whether it forgets, but which pushes, and how many it keeps.

Holding a list · 4

A list of 16 matches the holder profile's 16 positions. Each list starts from a reset and a fresh brain.
