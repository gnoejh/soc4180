Changing the cerebellum

w = profile("walker")
regions = {
    "cerebellum.forward": {"d_g": 2048, "s": 128, "eta": 0.5},
    "cerebellum.brace":   {"tau": 0.9, "eta": 0.3},
}
wiring = Wiring(w.name, w.contract, regions=regions,
                inputs=dict(w.inputs), outputs=dict(w.outputs))
brain = Brain(wiring, m)
brain.bracing = True    # False: it still learns, but sends no counter-move

Same wiring, new numbers. lab_cerebellum.py does exactly this from its command-line flags, so in class 2 you change a flag, not the code.
