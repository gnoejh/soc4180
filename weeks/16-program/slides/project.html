The project

Three weeks, one question, measured

  1. A question about the brain in the G1 (does it remember where, learn which, adapt to what?).
  2. A prediction written first, from a law or a reason, with a number.
  3. A twin: the same run with one part changed (a fresh brain, a region silenced, a different variant) so a difference has a cause.
  4. The measurement, from a script that writes its numbers to a file.
  5. The demo: the saved brain, loaded, in the viewer.
