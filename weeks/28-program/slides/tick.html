Part 2 · One tick

A dictionary in, a dictionary out

  • In: one value per attached input stream, by its address ("sense.vision", "reward"); None when it carries nothing this tick.
  • Inside: relay, gate, hold, value, remember, predict, choose; in that order, every tick.
  • Out: one value per output stream ("action", "state").
  • Time is the tick count. Nothing happens between ticks.
