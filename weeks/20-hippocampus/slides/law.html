Part 2 · The law

An episode in one vector

Code

z = code(percept)

each direction a fixed random vector of D numbers

Bind

r_i ⊛ z

circular convolution with slot i's random role

Mark

P^i ( ... )

a permutation applied i times: the position

Store

x ← x + P^i ( r_i ⊛ z_i )

added to the one episode vector, at once

Recall

nearest( r_i ⊘ P^-i x )

undo, unbind, take the direction whose code is nearest

Recall of slot i gets the right code plus the other k − 1 items, scrambled: crosstalk. It grows with the number of pushes k and shrinks with D. A wrong direction wins when the crosstalk makes it look closer than the right one.
