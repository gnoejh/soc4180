The method

Five parts, in this order

  1. A question about the brain in the G1.
  2. A prediction, written before the run, with a number and its reason.
  3. A twin: the same run with one thing changed.
  4. A measurement: a script that writes its numbers to a file.
  5. A check: one line that says PASS or FAIL, decided before the run.
