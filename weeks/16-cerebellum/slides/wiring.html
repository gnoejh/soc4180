Part 3 · The code

The anatomy, as a file: walker.toml

[regions."cerebellum.forward"]
d_g = 2048    # granule cells
s   = 128     # active at once
eta = 0.5     # learning rate
[regions."cerebellum.brace"]
tau = 0.9     # trace fading per tick
eta = 0.3     # learning per trial
[inputs]
"cerebellum.forward.proprio" = "proprio"
"cerebellum.forward.command" = "goal"
"cerebellum.brace.proprio"   = "proprio"
"cerebellum.brace.cue"       = "tone"
[outputs]
walk = "goal + cerebellum.brace"

Regions and their parameters: the numbers you will change.

Inputs: which sense feeds which port. The forward model also gets the command: an efference copy.

Outputs: the walk command is your goal plus the counter-move.

The cerebellum in a walking robot · 13

The profile is the brain’s anatomy in a dozen lines: which regions exist, their parameters, and how senses and actions are wired. Shortened here; in Python, profile("walker") returns the same thing. The efference copy is a real cerebellar idea: the forward model must know what was commanded to predict what will happen.
