Part 1 · What is in the file

brain.save(path): one .npz file, 1.8 MB for the walker

Header

wiring, body, codecs

the anatomy file, the body's name and digest (mujoco/g1, 4815eedf56d0), every codec's fingerprint

Regions

matrices, traces, tables

the forward model's read-out (2048 granule cells), the brace's learned counter-move

Randomness

every generator

the brain's and each region's: the next draw continues the sequence

Time

tick count, last outputs

2621 ticks for 12 pushes; a recurrent edge reads last tick's outputs

Brain.load(path, body) rebuilds it from the file alone. The file is read without running any code of its own: only ubrain's classes are rebuilt.

A brain's life · 4

The header can be read without rebuilding anything: ubrain.state.read_header(path). The size is mostly the forward model: 2048 granule cells times 41 predicted channels, plus its random expansion G.
