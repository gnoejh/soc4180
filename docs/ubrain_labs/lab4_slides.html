The cerebellum in a walking robot · 2

Part 1 · Principles

What the cerebellum does

It predicts what a movement will do to the body, and times actions to what is about to happen.

Most of the brain’s neurons

About four in five neurons sit in the cerebellum, nearly all of them tiny granule cells.

Damage: clumsy, not paralysed

Movements still happen, but overshoot, wobble and come at the wrong moment (ataxia).

It learns from mistakes

One dedicated wire per cell reports the error; the cell corrects itself.

Part 1 · Principles

The circuit, in five parts

Mossy fibres

the input: body state and command

Granule cells

expand: very many cells, few active

Purkinje cells

read out: the prediction

Output

deep nuclei, then movement

Climbing fibre

the teacher: the error

From the inferior olive. One climbing fibre per Purkinje cell: its spike says “you were wrong”.

Granule axons run as parallel fibres; each Purkinje cell hears up to two hundred thousand of them.

The cerebellum in a walking robot · 4

Part 1 · Principles

The Marr–Albus idea (1969, 1971)

1

Expand

Spread a few inputs over very many granule cells, only a few active at once. States that looked alike become easy to tell apart.

2

Read out

A Purkinje cell adds up the active granule cells, each through its own synaptic weight.

3

Correct

When the climbing fibre reports an error, change only the synapses that were active just then.

All the learning lives in one place: the granule-to-Purkinje synapses.

The cerebellum in a walking robot · 5

Part 1 · Principles

The forward model, in five lines

Mossy fibres

c = [ body , cmd ]

70 body numbers and the 3-number walk command

Granule cells

g = kWTA( G c )

G random and fixed; keep the k largest, centre, scale to length 1

Purkinje cells

ŷ = M g

the predicted change of the body over the next tick

Climbing fibre

e = y − ŷ

what really happened, minus what was predicted

Learning

M ← M + η e gᵀ

the delta rule: only active cells change

In the lab: G has --granules rows (2048), k is --active (128), η is --eta-forward (0.5). The score is the error as a percentage of the error of predicting “no change”.

Why sparse? Shared cells mean interference

Dense: every cell fires

State B

Shared: 12 of 12. Correcting A moves B’s prediction too.

Sparse: a few fire

Shared: 0 of 12. Correcting A leaves B alone.

The cerebellum in a walking robot · 7

Part 1 · Principles

Learning from the error: the step size η

Each tick, the prediction moves a fraction η of the way toward what really happened.

Small η

Safe but slow: it takes many strides before the predictions are good.

Large η

Fast, until each correction is bigger than the error it corrects. Then it overshoots, and the error grows instead of shrinking.

For class 2: where is the edge? You will find it with --eta-forward.

The cerebellum in a walking robot · 9

Part 1 · Principles

How the brace learns: fading traces

Delay line

unit j, j = 0 … 39

unit j fires j ticks after the tone (0.8 s in all)

Trace

E_j(t) = τ^(t − j)

fades by τ every tick: --tau

Kick (error)

κ(t)

the jolt the body got this tick, from the pelvis accelerometer

Credit

S_j = Σ_t κ(t) E_j(t)

every unit still glowing shares the blame

Learning

M ← (1 − η) M + η S

once per trial: --eta-brace

Counter-move

cmd ← cmd − γ M_j

j ticks after the tone, step against the kick to come

A unit is credited with every kick after it, through its trace, so the counter-move ramps up before the push lands.

The cerebellum in a walking robot · 13

Part 3 · The code

The whole loop: sense, tick, act

from ubrain import Brain, profile, act_03, manifest_from_hello_03, senses_from_state_03
from ubrain.bodies import BodyClient, start_body
proc, port = start_body(viewer=True)          # the G1, in its own process
body = BodyClient("127.0.0.1", port)
m = manifest_from_hello_03(body.hello)        # what this body offers
brain = Brain(profile("walker"), m)
state = body.reset(0)
for t in range(1500):                         # 30 s at 50 Hz
    senses = senses_from_state_03(state) | {"goal": (0.5, 0.0, 0.0)}
    action = brain.tick(senses)               # the cerebellum runs here
    state = body.act(*act_03(m, action))
print(brain.forward.stride_ratio)             # error vs “no change”

One call, brain.tick(senses), is one step of the whole brain: 20 ms of the robot’s life.

Part 3 · The code

Changing the cerebellum

w = profile("walker")
regions = {
    "cerebellum.forward": {"d_g": 2048, "s": 128, "eta": 0.5},
    "cerebellum.brace":   {"tau": 0.9, "eta": 0.3},
}
wiring = Wiring(w.name, w.contract, regions=regions,
                inputs=dict(w.inputs), outputs=dict(w.outputs))
brain = Brain(wiring, m)
brain.bracing = True    # False: it still learns, but sends no counter-move

Same wiring, new numbers. lab_cerebellum.py does exactly this from its command-line flags, so in class 2 you change a flag, not the code.
