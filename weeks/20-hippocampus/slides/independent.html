Part 3 · Two kinds of error

The memory keeps the robot's mistakes

pushed L BR BR L F FR L L perceived L B BR L F F L L # 6/8: the sense erred twice recalled L B BR L F F L L # 8/8 as perceived: memory kept both

Memory is scored against the percept: it stores what the robot thought happened. So the two errors multiply: both ≈ perception × memory (D 64, 8 pushes: 0.90 × 0.94 = 0.85; measured 0.88).

A memory cannot be better than the sense that fed it, and nothing in it marks which of its memories began as mistakes.
