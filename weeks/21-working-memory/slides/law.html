Part 2 · The law

One vector that fades with every write

Write

x ← γ x + P^j ( r_j ⊛ z_j )

fade everything, then add push j at its position

Weight

w_j = γ^(L−1−j)

the newest weight 1; one write older, γ; two, γ²

Recall

nearest( r_j ⊘ P^-j x )

unbind position j, take the nearest direction

Count

Σ_j a( w_j ; d, V )

each push's chance at its weight, summed: buffer_count

The newest push is loud and its crosstalk is the faint old ones; an old push is faint and its crosstalk is the loud new ones. So recall falls with age, and how fast depends on γ, on d, and on the 8 directions.
